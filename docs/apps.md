# Apps

- **Android (phones and tablets)**: download the APK from [Releases](https://github.com/Spacegoose02/Nighttime-Ninja/releases). On first launch, enter your server's address. To sign in, open **Settings → Pair a device** on a computer and type the code on the tablet.
- **Windows**: download the installer or portable EXE from [Releases](https://github.com/Spacegoose02/Nighttime-Ninja/releases). Change servers from the app menu.
- **Any browser**: open your server and use “Add to Home screen” to install it as an app.

Both native apps are thin wrappers around your server's web app (see `apps/launcher`, `apps/desktop` and `web/capacitor.config.ts`), so they always match the server version.
