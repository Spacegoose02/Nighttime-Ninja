# Security

Nighttime Ninja is often put on the internet, so security reports matter a lot.

## Reporting a problem

Please **don't** open a public issue. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/Spacegoose02/Nighttime-Ninja/security/advisories/new).

Include what you found, how to reproduce it, and which version you tested. You'll get a reply as soon as possible, and credit in the release notes if you'd like it.

## Supported versions

Only the latest release gets security fixes. The app tells admins when a newer release is out.

## Running it safely

See [Putting it on the internet](docs/settings.md#putting-it-on-the-internet): use https behind a reverse proxy, keep sign-up invite-only, and turn on two-factor or passkeys.
