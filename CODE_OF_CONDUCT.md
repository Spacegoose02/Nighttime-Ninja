# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep criticism about the work, not the person. Harassment, insults and personal attacks aren't allowed anywhere in the project: issues, pull requests, discussions or anywhere else you're representing it.

If something happens that makes you uncomfortable, contact the maintainer privately through GitHub (see [SECURITY.md](SECURITY.md) for the private reporting link). Reports are kept confidential. Maintainers may remove comments, lock threads or block people who don't follow these rules.
